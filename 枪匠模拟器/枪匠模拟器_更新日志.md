### 二、规则修正 · 槽位兼容

- **枪口按弹头直径归一**：`.300AAC` 与 `7.62×51` 同组（5.56/7.62/5.45/9mm/12号…），
  `Muzzle.Antreg`（VULKAN M1）归 5.56、`Muzzle.BenelliM4` 归 12 号。
- **镜环统一落在导轨位**：`Oring` 全系列 → `Rail.Collimator.Large`；低轮廓版 → `.Medium`
  （M1A 第4代钢座只给 Medium/Small）。原数据把 `Mount.MP5` 当占用位，枪上没这槽时
  连候选都不会算。
- **镜环只有在导轨件上才放行**（`byRail`）：M700 皮卡汀尼可以，1911 握把座不行——
  两者开出的槽名完全一样，只能按当前实际来源判断。
- **M-LOK 槽长限制**：两侧只有 3/5 槽、底部只有 5/7/9；前握把分「直装型」与「导轨型」
  （名字带 `Mlok` 的是导轨型）。
- **SIG 准星 / Magpul 备用准星**同时兼容「长」「短」两档。

### 三、语义修正 · 同名槽的两种含义

同一个槽名由不同的件提供时，含义可能完全不同：

| 槽名 | 枪身/护木给 | 镜环给 |
|---|---|---|
| `Sight.30mm.Low.Big` | **照门（大）**位 → 只放机械瞄具 | 30mm 低镜位 → 只放光学镜 |
| `Rail.Mount.Sight.*` | 真实导轨 → 可用 | 瞄具座开出 → **死接口**（实测装不进） |

同时把**全息/红点镜统一归到 `Rail.Collimator.*`**（准直式瞄具族）——HWS EXPS 系列原本
落在「瞄具基座（长）」，导致 AK 侧基座、MP5 低轮廓座、UMP 三导轨这些只给短位或不给该族的
中间座全部装不上（一次修正 +33 件次）。

### 已知限制

- **`_t_presets.js` 对装件顺序敏感**：按预设数组硬装时，若「A 依赖 B、A 排在 B 前」，
  会误报装不上（页面上按 UI 顺序点则正常）。这是测试工具缺陷，不影响页面。
- `Rail.Sight` / `Rail.Mount.Sight.*` 由瞄具座开出时显示为空行 + 提示「该接口在此枪上不可用」
  （用户 2026-11-16 实测）。

## V0.2.3 · 2026-11-16

### 修：M-LOK AFG 的「后坐力控制」显示成 -8%

用户拿游戏内卡面对：**M-LOK AFG（豺狼连队）后坐力控制 +20.0% · 人体工学 +5.0%**，

## V0.1.1 · 2026-11-16

> V0.1 刚发给测试者之后的一轮修补。判定规则、界面、方案码都动了，所以单独记一版。

### 新增：改枪码（导出 / 导入）

槽表上方的「配置方案」条（两行两块）：第一行「导入方案 / 导出方案」，第二行「码 + 复制」。
点导出生成一串码，别人粘进输入框点导入就能还原同一套配置。

**格式**：`G2-<枪2位>-<件数2位>-<比特流，每 6 字符一组>-<校验1位>`

长度是设计出来的 —— 目标是「三角洲那种几十个字符」，靠两件事：

| 手段 | 说明 |
|---|---|
| **不存槽位** | 件的默认占用位在数据里唯一（`P[a][4]`），装在哪本来就推得出来 |
| **位打包** | 不是每件固定宽度，而是把所有索引拼成**一条比特流**再按 5 bit 切字符 |

具体位宽：每件 **11 bit**（1337 件 < 2048），例外数 5 bit，每条例外 `序号 5 bit + 槽 9 bit`（441 槽 < 512）。

**例外表是怎么回事**：绝大多数件的默认位就是它实际装的位置，一个比特都不用多花；
只有灯/激光这类「一件能装好几个 `Rail.*`」的件，才追加一条例外记录它在哪个槽。
所以普通配置里例外数是 0，那个字节基本白送。

**长度对比**（M4A1 满配 24 件）：

| 写法 | 字符数 |
|---|---|
| 4 字符/件、存槽 | 119 |
| 位打包、存槽 | 97 |
| **位打包、不存槽（现行 G2）** | **73** |

**示例**：

```
G2-1G-0R-06MGMR-4FGAW6-HKERPN-6P5S9P-N4JP5G-799324-BJDXXW-TNF6PS-M2T540-X
```

字母表用 **Crockford Base32**（去掉容易看错的 `I L O U`）；解析容错：忽略分隔符与空格、
统一转大写、`O→0`、`I/L→1`。末尾 1 位校验和，抄错会直接报「校验位对不上」。

**稳定性**：件索引 = `Object.keys(parts)` 的下标、槽索引 = `DB.slots` 的下标，
两者 Python 侧都按名字排序构建，与文件系统遍历顺序无关；以后新增配件只追加在末尾，老码仍解得开。
版本差异过大时报「编号越界」，不会悄悄装错。

**还原顺序**：不是逐个塞 —— 有些件的槽要等上一个件开出来才存在（机匣 → 护木、转接座 → 缓冲管），
所以按「本轮槽已存在」的先放，迭代最多 6 轮；放不进的会明确列出来，不会静默丢弃。

### 判定规则：灯 / 激光

- 能装的位置 = socket 里列出的**全部** `Rail.*`（预设反解：DBAL-PL / X400V / Klesch-1 → `Rail.Pistol`，X300U → `Rail.BottomFront`）。
- 若 socket 里含 `Muzzle.*`，说明也占枪口下方那段空间 → **与消音器冲突**。
- ✅ 实测分界：DBAL-PL / X300U / X400V / Klesch-1 受影响；ADE / NcStar 激光与手电不受影响。

### 界面

- 顶部固定「本工具由「**繁星攻略组**」提供」+ 右侧「**联系我们 ▾**」下拉（小黑盒主页），与《物品产出查询》同一套视觉与交互。
- 改枪码条放在**枪名之上**，两行两块：第一行「导入方案 / 导出方案」，第二行「码 + 复制」。

### 修复：两段式槽被误判互斥

MCX 装「MCX缓冲管转接座」（占 `Stock.MCX`）→「KAC缓冲管」（占 `BufferTube.AR15`、开出 `Stock.AR15`）

### 判定规则

**① 槽位是长出来的，不是写死的**

枪身给根槽，装上件后把它 `provides` 的接口并进来，下游槽位实时出现。
所以「先装机匣才会掉护木」「转接座装上才出现缓冲管位」这类顺序都对。

**② 基础功能部件（缺了报「武器不可用」）**

```
Receiver · Barrel · Gasblock · Handle · Slide · PistolGrip · Stock · BufferTube · Handguard
```

例外与实测：

| 槽 | 结论 | 依据 |
|---|---|---|
| `Handle.AK`（AK 全系） | **不必需** —— AK 的拉柄与枪机框一体，槽里只是改装件 | ✅ 实测 |
| `Handguard.UMP` | 不必需 | ✅ UMP45「刚需上机匣，可以没有护木」 |
| `Handguard.M1A`（M1A / M14） | 不必需 —— 手持位置跟枪托一体，护木只是上层覆盖 | ✅ 实测 |
| `Handguard.AUG` / `AUGA3` / `ForegripAug` | **三选一**（护木与前握把至少一个） | ✅ AUG 实测 |
| `Stock` / `Gasblock` / `BufferTube` | 必需 | ✅ 实测（缓冲管：只装转接座不装管会报缺） |
| `Magazine` | **不必需** —— 缺了不能持续开火，但不算缺基础件 | ✅ 实测 |
| `PistolGrip.1911` | 必需，但装「握把瞄具座 / CC3P」也算填上 | ✅ 实测 |

**③ 同组规格与互斥**

- 同一物理位置的多规格（`Barrel.1911.Long/Short`、`Receiver.AK.Cover/Rail/Zenitco`）合并成一行下拉，选了自动替换。
- 合并条件是三条同时满足：**共同父路径** + **父路径带平台段** + **两边互为别名**（对方槽的候选全装得进本槽）。
- **两段式槽名（`X.Y`）不判兄弟**：`Mount.MP5` 与 `Mount.MP5SD` 是两个不同的座，`Stock.AR15` 与 `Stock.ArchRiser` 是枪托与托腮板，都能共存。
- 父子例外：已装件的 `provides` 里有对方占用的槽 → 不互斥（枪托提供枪托垫、转接座提供新托位）。
- **转接座整类不参与「多平台适配」**：它「占用 A 托位、开出 B 托位」，第二个托位是输出，不是安装位。

**④ 瞄具的占用位怎么定**

瞄具件的 socket 表把「它开出什么」和「它能装在哪」写在同一行，按目录定向会 fallback 到字母序第一个。三条纯数据判据修正：

1. **真槽** = 枪身根槽 ∪ 提供者里含非瞄具件的槽（否掉「某件自己开出的专有底座」）
2. **平台段优先**（必须排除 `mount`/`rail`/`sight`/`collimator` 等通用词，否则等于全命中）
3. **段重合兜底**（与原始占用位重合段最多的真槽）

**⑤ 两个「死接口」**

`Rail.Mount.Sight*` 与 `Rail.Sight` 在 575 套官方预设里**被占用 0 次**。
由**瞄具座**开出时属于死接口 —— 槽位照样显示「瞄具基座」，但下拉装不进东西。

依据：✅ 实测 1911 握把瞄具座**不兼容 EXPS2/EXPS3、OKP7**（它们的占用位正是 `Rail.Mount.Sight.Long`），
**Mosin PU 必须用专用镜座**。
反例保护：M4 上机匣也提供同名槽，那必须能用（官方预设里 M4 装全息就这么装），
所以判据是「提供者**全是瞄具座**」才屏蔽。

### 已知问题

1. **修正值按线性相加显示** ⚪ —— 游戏内是加法、乘算还是有上限，没验证。
2. **MOA 只取最后一件的值** —— 同时装两个带「角分」的配件会算错。
3. **配置不能保存 / 分享** —— 刷新即丢。
4. **`Mount_G36IronsightRail` / `Mount_G36SOpticrail`** 会出现在 Benelli M4 的「准直式瞄具」里 🔴
   —— 它们只有通用 `Rail.*` + `Sight.G36`，没有 `Mount.G36` 可判。
5. **O形环 / 各种枪口转接头**的占用位仍不准（预设重建失败的 9.6% 主要是它们）。
6. **SKS 内置 / 外置弹匣**有 1 处互斥未解释（`Magazine.SKS.Internal` ↔ `.External`）。
7. **耐久度下降后的修正值**未建模（只显示满耐久标称值）。
