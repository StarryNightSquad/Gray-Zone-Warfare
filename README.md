# Gray Zone Warfare · 数据工具

两个**单文件、纯离线**的 HTML 工具，双击即开 —— 不用安装、不用联网、不用启动服务。

数据全部来自游戏客户端资产（GZW **0.5.0**，manifest `4970906435234985650`）的解包结果：
配件接口、修正值、重量、价格、容器产出都是按资产结构解析出来的，不是人工录入。

## 物品产出查询

**2320 件物品 × 79 个来源**：世界战利品（容器 + 露天刷点）、7 个商人货架、敌人装备、任务需求。

能回答：

- 某个配件 / 药品 / 钥匙**在哪拿**，容器等级、区域、商人是否直售
- 某把枪的**所有产出渠道**（含「整枪预设」—— 箱子和商人卖的不是单件，是一整套装配）
- 某个容器**能刷出什么**
- 哪些东西**没有任何获取渠道**（未实装 / 未上架）

逐版改动见 [`物品检索工具/更新日志.md`](物品检索工具/更新日志.md)，
编号规则见 [`物品检索工具/物品产出查询_版本记录.md`](物品检索工具/物品产出查询_版本记录.md)。

## 枪匠模拟器（实验版）

**87 把枪 × 1337 件配件**，按游戏真实的 socket 关系推导槽位与兼容性。

能回答：

- 装上某个配件后**会新开出哪些槽位**（机匣 → 护木、转接座 → 缓冲管 → 枪托）
- 某个槽位**能装哪些件**，哪些件**互相顶掉**（标红并注明顶掉谁）
- **缺什么会导致「武器不可用」**（`MissingBaseFunctionalPart`），缺的那一行标红
- 一套配置**导成一串改枪码**，别人粘进去就能还原（G2 格式，满配约 73 字符）

> 这是**实验版**：必需件判定只对已实测的条目负责，互斥与同组按 socket 关系推导，
> 修正值按线性相加显示（游戏内是否乘算未验证）。已知问题列在工具页脚与更新日志里。

逐版改动见 [`枪匠模拟器/枪匠模拟器_更新日志.md`](枪匠模拟器/枪匠模拟器_更新日志.md)。

## 用法

1. 点进对应文件夹，下载其中的 `.html` 文件
2. 双击打开（Chrome / Edge / Firefox 都可以）

> 个别浏览器对本地 HTML 有额外限制。打开是空白页时，看同目录的「下载到本地再启动」说明。

## 检查更新

两个工具的页面顶部都有「**检查更新**」按钮：点一下读仓库根目录的 [`version.json`](version.json)，
与当前页面版本比对 ——

- 已是最新 → 绿色提示当前版本
- 有新版本 → 橙色提示版本号，去群文件或小黑盒取新版
- 没联网 → 灰色提示检查失败（不影响正常使用）

这个按钮只在点击时联网一次，其余时间页面完全离线。

## 反馈
