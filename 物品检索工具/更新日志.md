# 更新日志

Gray Zone Warfare **物品产出查询** —— 一个单文件、纯离线的查询页（`物品产出查询.html`），
配套一套从游戏资产里解出来的索引（`Index/`）。

- **数据基线**：GZW 0.5.0（manifest `4970906435234985650`）
- **页面**：双击 `物品产出查询.html` 即可用，无依赖、无联网
- **版本号只跟踪工具与数据本身**，与游戏版本无关
- 编号规则见 [`物品产出查询_版本记录.md`](物品产出查询_版本记录.md)：MAJOR 破契约 / MINOR 加东西 / PATCH 修东西

- **制退器 / 消焰器**：HYPERTAP 5.56 制退器（效率 +45.0% / 精度 -10.0%，0.085 kg）→ 3 值 `[45, 10, 20]`，
  **效率 `v[0]`、精度 `-v[1]`**。44 件 / 196 行。
- **瞄具**：ACOG TA01NSN 4x32（人体工学 -8.0%，0.424 kg）→ 工效**不在光学块里**，
  而是光学块之前单独一对负整数 `[-8, -13]`，取第一个；VUDU 3.5-18 同样（`[-12, -20]` → -12%）。
  30 件 / 128 行。

带修正值的配件行 1441 → **2301**（枪托 499 / 枪管 329 / 护木 322 / 弹匣 305 / 握把 214 /
枪口 196 / 枪身 185 / 瞄具 128 / 消音器 123）。

### 修正
- 槽位名统一为中文（`PistolGrips`→握把、`Firearms`→枪身、`BufferTube`→缓冲管、`Attachments/Mounts`→镜座…），
  `Index/part_mods.tsv` 新增第 7 列「瞄具工效」。
- **瞄具工效只认「恰好 2 个值、都是整数、都在 [-60, -0.5]」的链**：单值链全是噪声
  （`-14.25` 是那个全库填充常量，`-7.76` / `-0.90` / `-32.05` 也是噪声），
  按「有没有负值」筛会把 27 个机瞄读成 -14.25。

### 仍缺

- **制退器 / 消焰器 4 值**（21 + 4 件）：与 3 值的字段数不同，未定序。
- **瞄具光学块**（视场角 / 倍率 / 归零）：只认出倍率写在名字里，数值不填。

## [0.12.0] — 2026-11-15

### 新增
- **弹匣的修正值**：`PMAG 5.56x45/.300 BLK 30发弹匣` 实测卡（装填速度 **-4.0%**）对应值块 `[4, 11]`，
  存的是 +4、显示的是 -4 —— **反号**。容量方向也对得上：10 发 **+8%**、20 发 **+2%**、
  30 发 **-4%**、60 发弹鼓 **-10%**。覆盖 305 行配件条目。
- **枪身的修正值**（5 值布局）：AK-12 卡（人体工学 +9.0% / 精度 2.80 角分）对应 `v[1]`、`v[3]`，
  覆盖 185 行。3/2/4 值布局仍未定，不显示。

带修正值的配件行累计 **1052 行**（枪管 329 / 弹匣 305 / 枪身 185 / 消音器 123 / 枪托 110）。

### 修正
- **`MP_*` 预装弹匣回退到基础弹匣取修正值**：这类资产自己的值块是垃圾，但物理上就是「基础弹匣 + 预装弹药」，
  去 `MP_` 与 `_L<n>` 后按前缀匹配到 `Mag_*`，否则预设里那 106 行弹匣永远没有数值。
- **挡掉「像百分比但不是装填速度」的字段**：`12.902/10.957` 在 AK-308、G3、M1A、1911 7 发上重复，
  7 发弹匣不可能比 30 发慢 12.9% → 只显示整数、|值|≤20 的。

### 仍缺
- **枪托 / 握把的 5、6 值布局**：两行数值相等的样本（AK-74M 3.0/3.0、AK 聚合物握把 1.0/1.0）
  判不出先后，仍需一张两行不等的卡。

## [0.10.1] — 2026-11-15

### 修正
- **澄清价格口径**：配件表的 `$` 列改为 **`基础价$`**。这个数是物品资产里的**基础价值**，
  不是某次成交价 —— 卖给**对口商人**可得 100%，卖给**其他商人**约 **75%**。

  交叉验证（社区价格表 vs 客户端直读，四例全中）：

  | 物品 | 客户端值 | 对口商人 | 其他商人 |

  | 信用卡普卡 | 600 | 600（Artisan） | 450 = 0.75× |
  | 深色珍珠项链 | 1350 | 1350（Turncoat） | 1012 = 0.75× |
  | 宝石戒指 | 820 | 820（Turncoat） | 615 = 0.75× |
  | 单反相机 | 1280 | 1280（Handshake） | — |

- **购买侧仍未实测**：客户端里属性名被剥离，找不到「购买加价系数」。
  按通行做法买价即基础价值，但这条标 🟠 不写死 —— 一张购买界面截图即可确认。

## [0.10.0] — 2026-11-15

### 新增
- **配件的修正值（游戏里那串 +20% / -18%）**。这些数不在资产尾部那个 50 字节结构里，
  而是**另一串连续 float32**，位置在本地化 key（`<资产名>_Name`）之前几百字节处，起点还不一定 4 字节对齐。
  1466 件配件全部抽出（`Index/part_mods.tsv`），产出脚本 `tools/parse_part_mods.py`。
- 预设配件表里，标定过的槽位会在配件名下面多一行绿字，如
  `初速+20% · 精度1.11角分 · 工效-18%`（枪管）、`效率+15% · 响度+60% · 精度+10% · 工效-5%`（消音器）。

### 已标定 / 未标定
- **枪管**（82 件）：字段顺序按 5 值 / 6 值两套（第 2 字段为 0 时整项不存，后面各字段前移一位）。
- **消音器**（49 件，4 值的那 43 件）。
- 其余槽位（瞄具 / 枪托 / 握把 / 护木 / 弹匣 / 机匣…）**字段顺序还没标定，宁可不显示**。

### 验证
- 用玩家提供的 4 张配件卡逐项对照，全中：M16A1 20″（初速+20% / 1.22MOA / 工效-18%）、
  M700 VTR 22″（+2% / 0.55MOA / +1%）、SOCOM556 RC1（效率+15% / 响度+60% / 精度+10% / 工效-5%）、
  KAC 缓冲管（后坐力控制+6%）。
- 更强的自洽检验：AR-15 枪管随长度 **单调**——10.5″ 初速-3% → 14.5″ +5% → 16″ +8% → 18″ +12% → 20″ +20%，
  精度 3.89→2.15→1.83→1.44→1.11 MOA，人体工学 +11→+2→-2→-8→-18%。
  这里 14.5/16/18/20 的 +5/+8/+12/+20 **与弹道模型里用面板初速反解出的 g 值逐位相同**
  （`PENETRATION_MODEL.md`），两条互不相干的证据链对上了。
